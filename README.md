# PPG (UE v.5.2.1)

Projekt stanowi **ćwiczeniowy projekt realizowany w silniku Unreal Engine 5**, którego celem było opanowanie podstaw programowania gier poprzez implementację różnych mechanik.

## Zrealizowane funkcjonalności

* AI przeciwników z ruchem i prostym systemem logiki
* System ekwipunku (inventory)
* Przełączanie kamer (np. widok TPP/FPP)
* Podstawowe mechaniki sterowania i interakcji
* Eksperymenty z ruchem RTS (AI movement)
